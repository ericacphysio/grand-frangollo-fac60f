# Ace Body Physiotherapy & Wellness

Marketing website for Ace Body Physiotherapy & Wellness, a physiotherapy clinic. The site has three pages:

- **Home** (`/`) — a landing page introducing the clinic, its services, and how appointments work.
- **About** (`/about`) — a profile of physiotherapist Erica Chen, her background, and treatment philosophy.
- **Booking** (`/booking`) — an online booking page that embeds the clinic's Splose booking widget so visitors can schedule an appointment directly.

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React 19, file-based routing via TanStack Router)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Vite 7](https://vitejs.dev/)
- TypeScript (strict mode)
- Deployed on [Netlify](https://www.netlify.com/)

## Running locally

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:3000`.

To build for production:

```bash
npm run build
```

See `AGENTS.md` for a deeper look at the project structure and conventions.
